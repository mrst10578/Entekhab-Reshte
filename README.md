Data and tooling for the LoPRax RankLab admission dataset.

## ظرفیت پذیرش دانشگاه‌ها

[بخش مستقل ظرفیت پذیرش](data/capacity/README.md) برای پزشکی، دندانپزشکی، داروسازی و فیزیوتراپی؛ به تفکیک سال، دانشگاه و نوع دوره. ظرفیت سال‌های ۱۴۰۱ تا ۱۴۰۴ استخراج و با اصلاحیه‌های ارسالی تطبیق داده شده است. داده هر سال و خلاصه ظرفیت هر دانشگاه جداگانه در دسترس است.
