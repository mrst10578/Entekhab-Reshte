# LoPRax RankLab — Entekhab Reshte

Data and tooling for the LoPRax RankLab admission dataset.

Restored repository foundation after the previous repository became unavailable.

## ظرفیت پذیرش دانشگاه‌ها

[بخش مستقل ظرفیت پذیرش](data/capacity/README.md) برای پزشکی، دندانپزشکی، داروسازی، فیزیوتراپی، پرستاری، اتاق عمل، هوشبری، گفتاردرمانی، بینایی‌سنجی، شنوایی‌شناسی، مامایی و فوریت‌های پزشکی پیش‌بیمارستانی؛ به تفکیک سال، دانشگاه و نوع دوره. ظرفیت سال‌های ۱۴۰۱ تا ۱۴۰۴ استخراج و با اصلاحیه‌های ارسالی تطبیق داده شده است. مامایی و فوریت در فایل مکمل هر سال ثبت شده‌اند و عنوان دقیق منبع فوریت نیز حفظ شده است.
