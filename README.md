# LoPRax RankLab — Entekhab Reshte

Data and tooling for the LoPRax RankLab admission dataset.

Restored repository foundation after the previous repository became unavailable.

## ظرفیت پذیرش دانشگاه‌ها

[بخش مستقل ظرفیت پذیرش](data/capacity/README.md) برای پزشکی، دندانپزشکی، داروسازی، فیزیوتراپی، پرستاری، اتاق عمل، هوشبری، گفتاردرمانی، بینایی‌سنجی، شنوایی‌شناسی، مامایی، فوریت‌های پزشکی پیش‌بیمارستانی، علوم تغذیه و تکنولوژی پرتوشناسی؛ به تفکیک سال، دانشگاه و نوع دوره. ظرفیت سال‌های ۱۴۰۱ تا ۱۴۰۴ استخراج و با اصلاحیه‌های ارسالی تطبیق داده شده است. چهار رشته افزوده‌شده در فایل‌های مکمل سالانه ثبت شده‌اند؛ عنوان دقیق منبع فوریت حفظ شده و تکنولوژی پرتودرمانی از پرتوشناسی جدا نگه داشته شده است.
