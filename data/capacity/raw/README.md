# فایل‌های منبع ظرفیت پذیرش

فایل‌های دریافتی در پوشه سال مربوط نگهداری می‌شوند؛ برای نمونه، فایل‌های پذیرش ۱۴۰۵ در مسیر `data/capacity/raw/1405/` قرار می‌گیرند. این نمونه مسیر است و وجود داده ۱۴۰۵ را نشان نمی‌دهد.

نام فایل‌ها باید خوانا و یکتا باشد. دفترچه اصلی و اصلاحیه هر کدام فایل و شناسه مستقل دارند. نسخه‌های قبلی حذف یا بازنویسی نمی‌شوند.

فهرست [منابع](sources.csv) در حال حاضر فقط سرستون دارد.

| ستون | معنی |
| --- | --- |
| `source_id` | شناسه یکتای منبع، برای ارجاع رکوردهای ظرفیت |
| `year` | سال پذیرش |
| `file_name` | مسیر نسبی فایل از همین پوشه |
| `document_type` | نوع سند: دفترچه اصلی، اصلاحیه یا سایر |
| `version` | نسخه یا تاریخ انتشار، اگر مشخص باشد |
| `sha256` | اثر انگشت فایل برای تشخیص فایل تکراری |
| `source_url` | نشانی منبع، در صورت وجود |
| `notes` | توضیحات لازم، از جمله ارتباط اصلاحیه با دفترچه اصلی |

برای فایل ارسالی در گفت‌وگو، وجود نشانی اینترنتی ضروری نیست. سال نامشخص باید پیش از استخراج نهایی روشن شود.
