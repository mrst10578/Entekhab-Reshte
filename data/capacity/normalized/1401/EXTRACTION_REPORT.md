# گزارش استخراج ظرفیت ۱۴۰۱

دامنه: پزشکی، دندانپزشکی، داروسازی، فیزیوتراپی، پرستاری، اتاق عمل، هوشبری، گفتاردرمانی، بینایی‌سنجی، شنوایی‌شناسی؛ فقط بر اساس آرشیو ارسالی کاربر.

دفترچه اولیه ۱۵۷۶ ردیف داشت؛ ۰ ردیف افزوده و ۳ ردیف حذف شد. خروجی نهایی ۱۵۷۳ ردیف و ۲۱۳۸۳ صندلی دارد. تعداد ردیف با ظرفیت متفاوت است.

| رشته | ظرفیت نهایی |
| --- | ---: |
| پزشکی | ۹۰۱۲ |
| دندانپزشکی | ۱۸۶۰ |
| داروسازی | ۱۳۷۲ |
| فیزیوتراپی | ۳۷۶ |
| پرستاری | ۵۶۷۱ |
| اتاق عمل | ۱۳۶۶ |
| هوشبری | ۱۱۸۵ |
| گفتاردرمانی | ۲۵۵ |
| بینایی‌سنجی | ۹۱ |
| شنوایی‌شناسی | ۱۹۵ |

## سه رشته افزوده‌شده در این مرحله

گفتاردرمانی، بینایی‌سنجی و شنوایی‌شناسی مجموعاً ۵۸ ردیف دارند. عنوان اصلی «گفتار درمانی»، «بینایی سنجی» یا «شنوایی شناسی» در `notes` حفظ شده است. شنوایی‌سنجی نام رایج شنوایی‌شناسی است و ردیف مستقلی با ظرفیت تکراری ساخته نشده است.

در اصلاحیه‌های ارسالی این سال، ردیف تغییری برای این سه رشته پیدا نشد.

ده ردیف این سه رشته در جدول تعهد خدمت با نوع دوره نامشخص ثبت شده‌اند؛ دوره روزانه از نام دانشگاه حدس زده نشده است.

نام دانشگاه علوم توانبخشی و سلامت اجتماعی در ردیف‌های تازه پس از بازبینی عنوان تصویری جدول یکسان‌سازی شده است؛ عنوان خام جدول در فایل استخراج دفترچه و ارجاع صفحه باقی است.

## کنترل‌ها و حدود بررسی

ردیف‌های نهایی، خلاصه‌های دانشگاه و سابقه اصلاحیه هفت رشته قبلی از نظر مقدار تمام ستون‌ها با نسخه ثبت‌شده برابر هستند؛ فایل‌های خام آن‌ها نیز بدون تغییر حفظ شده‌اند. جمع ظرفیت، یکتایی کد، سال، رشته، نوع دوره، جمع جنسیت عددی و شناسه/شماره صفحه منبع کنترل شدند.

برای این سه رشته، کدهای کنار عنوان با یک جستجوی مستقل از مستطیل‌های جدول استخراج شدند و مجموعه کدها دقیقاً با خروجی برابر بود. نمونه جدول‌های هر چهار سال، عنوان دانشگاه توانبخشی، جدول تعهد خدمت و تغییر نیمسال‌های اصلاحیه به‌صورت تصویری بررسی شدند. همه صفحات به‌صورت تصویری بازبینی نشده‌اند.

دوره، نیمسال، جنسیت، تعهد خدمت و شرایط خاص در ردیف‌ها باقی می‌مانند؛ خلاصه دانشگاه نیمسال‌ها را جمع می‌کند و دوره/شرایط پذیرش را جدا نگه می‌دارد. اصلاحیه‌های خارج از آرشیو ارسالی بررسی نشده‌اند و اعداد ادعای مجموع همه منابع انتخاب رشته کشور نیستند.

اختلاف قبلی پرستاری همچنان حل‌نشده است: اصلاحیه اول صفحه ۱ کد ۳۲۲۷۶ را برای پرستاری ایرانشهر ـ پردیس پزشکی چابهار با ظرفیت ۶ نفر آورده؛ دفترچه صفحه ۷۵ همین کد را برای کاردانی فوریت‌های پزشکی شوشتر با ظرفیت ۱۸ نفر دارد. ظرفیت ۶ نفر وارد جمع پرستاری نشده؛ `unresolved_capacity_rows=1` و `all_amendment_codes_matched=false` به همین مورد قبلی مربوط است. سه رشته تازه ردیف حل‌نشده ندارند.
